# Atlas

Лендинг Atlas — инфраструктура для современного образования.

**Живая версия:** https://zhanuzak23.github.io/atlas/

## Структура

Весь сайт — один самодостаточный файл [`index.html`](index.html): разметка, стили и скрипты внутри. Внешняя зависимость одна — шрифты Google Fonts (Manrope, Instrument Serif).

## Дизайн

- Тёмная студийная сцена: направленный свет, перспективная сетка-пол, виньетка, зерно поверх страницы.
- Акцент — лайм `#CCFF33` на графите `#08090A`, светлые кремовые полосы для смысловых блоков.
- Мокапы устройств (телефон, монитор) нарисованы на CSS, внутри — живой интерфейс, а не картинки.

## Разработка

Отдельной сборки нет. Откройте `index.html` в браузере.

Публикация: пуш в `main` запускает workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml), который выкладывает содержимое репозитория на GitHub Pages.

## Что нужно заменить

- Ссылки WhatsApp и Instagram, почта `hello@atlas.kz` — заглушки.
- Числа внутри мокапов интерфейса — демонстрационные.
